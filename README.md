

## Overview

Developed an interactive Power BI dashboard to analyze employee attendance, leave trends, and performance metrics. The dashboard helps track workforce patterns and supports data-driven decision-making.

## Tools Used

- Power BI
- Microsoft Excel

## Key Features

- Attendance Analysis
- Leave Trend Monitoring
- Employee Performance Tracking
- Interactive Filters and Visualizations
- KPI-Based Reporting

## Business Impact

- Reduced manual reporting effort by approximately 3–4 hours per day.
- Improved visibility into employee attendance and leave patterns.
